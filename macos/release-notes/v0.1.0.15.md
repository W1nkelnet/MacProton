**Faster**
- Direct3D 11 games on KosmicKrisp need less CPU and GPU time. Kebab Chefs' main menu runs at 50 instead of 29 fps; Raft, Green Hell and Medieval Dynasty are 4–8 % faster, Rise of the Tomb Raider is unchanged.
- Mipmaps that games generate while running (Unity does this a lot) are now built in one compute pass per texture instead of one render pass per level.
- KosmicKrisp no longer makes Metal insert a synchronization pass after every render pass; the next pass waits instead, which keeps the same order. The old behavior can be restored with `MESA_KK_LIGHT_BARRIERS=0`.

**For developers**
- DXVK patch 0005 and Mesa patches 0034–0037; measurements and what did not help (DXVK's tiler mode off, deferring render passes for tessellation) are in `docs/MACOS_PORT.md`.
- New test program `docs/macos/d3d11-mipgen.c` checks generated mip chains level by level.
- Wine's D3D9 tests and vkd3d-proton's test suite give the same results as with v0.1.0.14.
