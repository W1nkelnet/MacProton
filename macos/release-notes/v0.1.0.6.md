**New**
- Upscaling: under “Display” in Settings you choose how Windows games reach a Retina display. “macOS (smooth)” is the previous behavior, “MetalFX Spatial (sharper)” upscales every frame to the display's full resolution with Apple's MetalFX, “Pixel-exact” suits pixel art. Applies to Direct3D and Vulkan games from the next game start.
- Shorter loading times: a game's shader translations now stay stored in its prefix instead of being created again on every start. Horizon Zero Dawn loads a save in 35 instead of 140 seconds.
- Current components: Wine 11.0 from Proton's `bleeding-edge`, DXVK `master` (3.1.1), vkd3d-proton 3.1 and MoltenVK `main`.

**Important after the update**
- The first start of a Direct3D 12 game takes very long once. vkd3d-proton 3.1 discards its old shader cache, and games such as Horizon Zero Dawn then compile all shaders again. We measured about 27 minutes on the loading screen. From the second start on, the game loads quickly again.

**For developers**
- MoltenVK patch 0009: `MVK_CONFIG_UPSCALING=metalfx` upscales swapchains to the display's pixels with MetalFX Spatial. MetalFX is loaded only at runtime.
- MoltenVK patch 0010: `MVK_CONFIG_SHADER_CACHE_DIR` keeps the SPIR-V to MSL translations in a file; `run.sh` sets the folder to `$WINEPREFIX/moltenvk-cache`. Set empty, the variable turns the cache off.
- Khronos has deprecated MoltenVK and recommends Mesa's KosmicKrisp on Apple silicon. MacProton stays with MoltenVK for now, because all macOS changes build on it.

**Still open**
- The Steam overlay does not work yet; store and profile open in the Steam window.
- Ratchet & Clank: Rift Apart hangs after its launcher.
- Games that require OpenGL 4.3 or later, such as Foundation, do not start.
