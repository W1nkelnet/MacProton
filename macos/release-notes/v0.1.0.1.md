**New**
- Welcome screen on the first start: sets up steamcmd with a progress bar and then leads to the Steam sign-in
- Search field for the games in the library
- Uninstalling games: the game folder and, if wanted, the Wine prefix go to the Trash, and the game leaves the library
- Mac versions can be uninstalled in Steam from the context menu
- New app icon

**Fixed**
- Unreal Engine 5 games such as Town To City lost the graphics device after a short time
- Games with Steam's copy protection (SteamStub) start
- .NET games such as Let's Build a Zoo start
- Compute shaders with shared memory are translated for Metal

**Installation:** Unzip, drag `MacProton.app` into Applications and allow it in the Gatekeeper dialog on the first start, or allow it once:

```bash
xattr -dr com.apple.quarantine /Applications/MacProton.app
```

More in the [README](https://github.com/W1nkelnet/MacProton#installation).
