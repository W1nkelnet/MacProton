**Neu**
- Willkommensbildschirm beim ersten Start: richtet steamcmd mit Fortschrittsanzeige ein und führt danach zur Steam-Anmeldung
- Suchfeld für die Spiele der Bibliothek
- Spiele deinstallieren: Spielordner und auf Wunsch der Wine-Prefix kommen in den Papierkorb, das Spiel verschwindet aus der Bibliothek
- Mac-Versionen lassen sich über das Kontextmenü in Steam deinstallieren
- Neues App-Icon

**Behoben**
- Unreal-Engine-5-Spiele wie Town To City verloren nach kurzer Zeit das Grafikgerät
- Spiele mit Steams Kopierschutz (SteamStub) starten
- .NET-Spiele wie Let's Build a Zoo starten
- Compute-Shader mit Shared Memory werden für Metal übersetzt

**Installation:** Zip entpacken, `MacProton.app` nach „Programme“ ziehen und beim ersten Öffnen im Gatekeeper-Dialog erlauben, oder einmal freigeben:

```bash
xattr -dr com.apple.quarantine /Applications/MacProton.app
```

Mehr im [README](https://github.com/W1nkelnet/MacProton#installation).
