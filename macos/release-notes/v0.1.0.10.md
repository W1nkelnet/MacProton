**New**
- Threads of Windows games now wait for each other directly in shared memory (fsync) instead of asking the wineserver every time. A wake-up between two threads takes 6 instead of 20 µs; Green Hell runs about 10 % faster. Needs macOS 14.4 or later; older systems keep the previous way.

**For developers**
- Wine patch 0006: fsync on macOS through `os_sync_wait_on_address`; `run.sh` sets `WINEFSYNC=1`, `WINEFSYNC=0` turns it off. No wait sleeps longer than 250 ms at a time, because macOS now and then swallows a wake-up.
- `docs/macos/synctest.c` checks Wine's sync objects.
