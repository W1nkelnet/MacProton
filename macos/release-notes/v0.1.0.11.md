**New**
- KosmicKrisp lets Metal build the shader pipelines in the background on all cores instead of making the game wait for every pipeline. The first start after an installation or an update is much faster: Horizon Zero Dawn has twice as many pipelines ready in the same time as before (8,644 instead of 4,240 in 15 minutes). In game nothing changes; Rise of the Tomb Raider still runs its benchmark at 27 fps.

**For developers**
- Mesa patch 0029: Metal libraries and pipeline states are created on a compile queue of the device (one thread per core). Binding waits for the build or builds itself; draws and dispatches with a pipeline Metal could not build are skipped.
