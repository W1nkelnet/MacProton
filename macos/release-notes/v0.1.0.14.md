**New**
- MacProton is now also available in English. The app follows the language of macOS. On the first start (top right) and in Settings under “Language” you can choose between German and English; the app restarts briefly for this.
- The window is larger on the first start, so everything fits.
- The app contains the license texts of all software it ships, with versions and sources. Open them through the menu MacProton › Licenses …
- MacProton's own code is now explicitly under the BSD license, like Proton itself.
- The “About MacProton” window names the projects used and states that MacProton is not affiliated with Valve.

**For developers**
- The app's texts are localizable. German is the source language; the English texts are in `macos/app/Localization/en.py`, from which `build-app.sh` generates `en.lproj/Localizable.strings`.
- `macos/collect-licenses.sh` collects the license texts from the source trees into `macos/licenses`, and `build-app.sh` puts them into the app.
- The README describes the current state (KosmicKrisp, Direct3D 12) and where the source code of every version is, and has notes on warranty and trademarks.
