**New**
- Downloads tab: shows running and waiting downloads with progress, size, speed and remaining time. Downloads can be paused, resumed and moved up. They run one after another and continue after MacProton restarts; MacProton recognizes started downloads in the game folder, also from older versions. On resuming, steamcmd checks the existing files and downloads only what is missing.
- Free choice of location: right-click a game → “Install In …”, for example on an external drive. Settings → “Location for Games” sets a default folder for new games.
- Moving games: right-click → “Move …”. To another drive the game is copied, with progress, and only then deleted at its old location.
- External drives: if the drive of a game is not connected, its card shows this right away instead of offering a download.
- Get cloud saves: the dialog shows which files belong to the game according to Steam and which are already imported, and uses the terms of the German Steam page.
- First support for Direct3D 12 through vkd3d-proton. So far only checked with a test of our own, hardly with games. Unreal Engine 5 games refuse Direct3D 12 and keep running with Direct3D 11.

**Fixed**
- Uninstalling also works for started downloads.
- Special characters such as “™” in game names could swallow parts of steamcmd's output.

**Good to know:** While steamcmd downloads, the Steam client is briefly offline. MacProton restarts it after the download or when pausing.

**Installation:** Unzip, drag `MacProton.app` into Applications and allow it in the Gatekeeper dialog on the first start, or allow it once:

```bash
xattr -dr com.apple.quarantine /Applications/MacProton.app
```

More in the [README](https://github.com/W1nkelnet/MacProton#installation).
