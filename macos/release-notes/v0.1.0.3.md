**New**
- Update detection: MacProton checks at start and every four hours whether installed Windows games have updates and shows “Update available” with a button. The check signs steamcmd in anonymously, so the Steam client stays connected.
- Download game updates automatically, as a switch under Settings → Updates
- Notice about new MacProton versions (once the repository is public)
- “Get Cloud Saves …” in the context menu: opens Steam's cloud page of the game and imports the files downloaded there to the right place, backing up replaced files. This way saves are there without starting the game first.
- Notice before the first start of a game with Steam Cloud saves that has never been synced on this Mac
- Metal HUD with FPS, as a switch under Settings → Display

**Fixed**
- A steamcmd session stayed open in the background after the library sync

**Good to know:** Steam does not download cloud saves of Windows games on the Mac before they start. If you last played on another device, get the cloud saves from the context menu first.

**Installation:** Unzip, drag `MacProton.app` into Applications and allow it in the Gatekeeper dialog on the first start, or allow it once:

```bash
xattr -dr com.apple.quarantine /Applications/MacProton.app
```

More in the [README](https://github.com/W1nkelnet/MacProton#installation).
