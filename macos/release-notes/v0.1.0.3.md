**Neu**
- Update-Erkennung: MacProton prüft beim Start und alle vier Stunden, ob installierte Windows-Spiele Updates haben, und zeigt „Update verfügbar“ mit Knopf an. Die Prüfung meldet steamcmd anonym an, der Steam-Client bleibt verbunden.
- Spiel-Updates automatisch laden, als Schalter unter Einstellungen → Updates
- Hinweis auf neue MacProton-Versionen (sobald das Repository öffentlich ist)
- „Cloud-Spielstände holen …“ im Kontextmenü: öffnet Steams Cloud-Seite des Spiels und importiert die dort geladenen Dateien an die richtige Stelle, mit Sicherung der ersetzten Dateien. So sind Spielstände da, ohne das Spiel erst starten zu müssen.
- Hinweis vor dem ersten Start eines Spiels mit Steam Cloud, das auf diesem Mac noch nie abgeglichen wurde
- Metal-HUD mit FPS, als Schalter unter Einstellungen → Anzeige

**Behoben**
- Nach dem Bibliotheksabgleich blieb eine steamcmd-Sitzung im Hintergrund offen

**Gut zu wissen:** Steam lädt Cloud-Spielstände für Windows-Spiele auf dem Mac nicht vor dem Start. Hast du zuletzt auf einem anderen Gerät gespielt, hole vorher die Cloud-Spielstände über das Kontextmenü.

**Installation:** Zip entpacken, `MacProton.app` nach „Programme“ ziehen und beim ersten Öffnen im Gatekeeper-Dialog erlauben, oder einmal freigeben:

```bash
xattr -dr com.apple.quarantine /Applications/MacProton.app
```

Mehr im [README](https://github.com/W1nkelnet/MacProton#installation).
