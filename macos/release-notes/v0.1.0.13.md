**New**
- Unreal Engine 5 games run with DirectX 12 on KosmicKrisp. Tested with Town To City (UE 5.7): the world is rendered completely. So far UE5 refused DirectX 12 and ran with DirectX 11. Now it picks DirectX 12 by itself.
- Fixes a single flat color instead of the game image. It appeared when a game reads a texture in a different shape than it created it in, which UE5 does for bloom and tonemapping.
- Shaders that share values across a SIMD group now compute correctly in loops. Before, every thread there got the same result.

**For developers**
- Mesa patch 0033: 2D and 2D array views carry a Metal view of the other type. `texture2d_array` declarations read it from a new field of the descriptor.
- Mesa patch 0032: SSA values are declared in the innermost loop that uses them. Otherwise Metal's compiler miscompiles waterfall loops. All 928 wave tests of vkd3d-proton pass.
- vkd3d patch 0011: feature level 12_0 on KosmicKrisp, as on MoltenVK.
