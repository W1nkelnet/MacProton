**New**
- Steam overlay in Windows games: Shift+Tab opens it, and store and profile pages a game calls up appear in the game instead of the Steam window. Can be turned off in Settings.
- KosmicKrisp is the new default: MacProton now runs Direct3D on KosmicKrisp, Mesa's Vulkan driver for Metal 4 (macOS 26 and later). Khronos has deprecated MoltenVK and recommends KosmicKrisp as its successor. In the games tested, KosmicKrisp is at least as fast, and clearly faster in Green Hell and Raft. MoltenVK can be chosen in Settings and per game in its launch options.
- Transform feedback (stream output) on KosmicKrisp, for Direct3D 11 and 12. MoltenVK cannot do this.
- OpenGL over Vulkan: in a game's launch options, “OpenGL over Vulkan (Zink)” turns on Mesa's Zink. It offers OpenGL 4.6 (64 and 32 bit), macOS itself only 4.1. Zink runs on KosmicKrisp.
- MetalFX upscaling now also works with Direct3D 12 games.
- Prefixes share the runtime's Windows DLLs as APFS clones and take about 500 MB less per game.
- Foundation starts: with OpenGL 4.6 through Zink, which MacProton turns on for the game itself.
- Games on exFAT drives: before the start MacProton removes the `._` files macOS puts next to every file there and that some games trip over (Foundation).
- Shaders are compiled on all cores at once. The first start after an update is faster, and games no longer stall behind compiles in the background.

**Good to know**
- If you already chose a graphics driver in Settings, it stays that way.
- MetalFX upscaling and “Pixel-exact” work with both drivers.

**For developers**
- Mesa patches in `macos/patches/mesa`: transform feedback with its queries based on Mesa's `poly`, line fill mode, timestamp pools over 4096 entries, present waits after GPU completion (Medieval Dynasty 60 instead of 30 fps), parallel shader compiles, MetalFX through `MTL4FXSpatialScaler`, `MESA_WSI_METAL_FILTER=nearest` and `MESA_KK_LIGHT_BARRIERS` as an experiment. Tests: `macos/tests/kosmickrisp-xfb/run.sh`, `macos/tests/kosmickrisp-present/run.sh`; GPU time from Metal System Traces with `macos/gpu-trace.py`.
- `build.sh` builds KosmicKrisp (step `kosmickrisp`) and Zink as the Windows `opengl32.dll` (step `zink`).

**Still open**
- Unreal Engine 5 with `-dx12` (Nanite) needs 64-bit atomics, which Metal only partly has.
- Sparse resources (tiled resources) are missing in both Vulkan drivers.
