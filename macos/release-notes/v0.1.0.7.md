**New**
- Steam Cloud sync for Windows games: Steam for macOS does not sync the saves of games without a Mac version, such as Raft, Horizon Zero Dawn, Medieval Dynasty or Town To City. MacProton now does it itself: before every start it downloads what changed in the Steam Cloud, after playing it uploads the new saves. If a file changed on both sides, MacProton asks which version should count; the other one is backed up first. To turn it on, sign in under “Steam Cloud” in Settings with the Steam app on your phone via QR code. MacProton never sees your password, and Steam on the Mac stays signed in. “Quit” on the game card cancels a running sync.
- Game Mode: macOS now turns on Game Mode for Windows games too while the game window is in front. Games then take priority over background tasks, and controllers and AirPods respond faster over Bluetooth.
- Platform filter in the library: next to “All / Installed / Downloads”, a menu shows all games, only Windows games or only those with a Mac version.

**Good to know**
- A game's first sync downloads all saves from the cloud and takes a moment for large saves: Town To City has 461 MB and needed about 80 seconds at 48 Mbit/s. After that, MacProton transfers only what changed.
- Games with a Mac version and games that save through Steam's cloud interface (such as Green Hell) are still synced by Steam for macOS.
- Backups are in `~/Library/Application Support/MacProton/save-backups`.

**For developers**
- For the sync, MacProton speaks Steam's client protocol over WebSocket (`SteamConnection.swift`), because the cloud methods of the Web API are open only to publishers. A login ID of its own keeps the Steam client on the Mac signed in; `ClientLogOff` would revoke the token and is sent only when signing out. The sync state per game is in `cloud-sync/<AppID>.json`.
- Wine patch 0005: `build.sh` puts `Wine.app` next to `ntdll.so`, and ntdll starts Windows programs from this bundle in the “Games” category.
